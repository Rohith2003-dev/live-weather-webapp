# live-weather-webapp
Live Weather Forecast App  This is a clean, single-page web application that provides live weather forecasts. It's built entirely with HTML, Tailwind CSS, and vanilla JavaScript, requiring no complex frameworks or setup.
**Key Features**

Live Weather: Get the current temperature, "feels like" temperature, humidity, and wind speed.

Geolocation: Automatically fetches the weather for your current location on page load (with browser permission).

Manual Search: Type in any city name to get its weather.

3-Day Forecast: See a simple forecast for the next three days, including average temperature and conditions.

Responsive Design: Looks great on both mobile devices and desktops.

No API Key Needed: Uses the free wttr.in JSON API, so it's easy for anyone to use or modify.
